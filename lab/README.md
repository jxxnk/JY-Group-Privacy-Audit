# JY Group Lab

가상 그룹의 신뢰경계, 계열사 연결과 접근통제를 재현한다.

- `before/`: 의도적으로 정의한 관리·기술 문제를 가진 개선 전 구성
- `after/`: 승인된 개선안을 적용한 구성

모든 대상은 로컬 VMware Host-only/NAT 또는 Docker 전용 네트워크에 둔다. 인터넷·실제 기업·제3자 시스템을 대상으로 스캔하지 않는다. 테스트용 IP는 RFC 5737 문서 범위 또는 사설 랩 주소를 쓰고 공개 전 치환한다.

대표 존은 홀딩스 관리존, 산업 HR존, 서비스 고객존과 수탁사 접근존이다. `before`와 `after`는 네트워크·계정·로그 통제 외의 애플리케이션 동작을 가능한 한 동일하게 유지한다.
