# 도구와 비용 구성

## 1. 확정 구성

최소비용을 고정 원칙으로 한다. Microsoft 365, VS Code, VMware Workstation, Kali Linux와 ChatGPT는 사용자가 이미 보유한 환경을 활용한다. 필수 신규 유료구매는 0원으로 설계한다.

가격은 플랜·환율·세금·정책에 따라 바뀔 수 있으므로 실제 결제 전 공식 가격을 다시 확인한다. 아래 비용은 프로젝트 기획 기준이며 월 구독료를 새로 지출한다는 뜻이 아니다.

## 6. Microsoft 365 활용 방식

| 앱 | 프로젝트 산출물 |
|---|---|
| Excel | 자산대장, 개인정보 처리현황, 통제 매트릭스, 증적요청목록, 위험대장, 전후 비교표 |
| Word | 착수·중간·최종 보고서, 수탁사 점검보고서, 개선계획서 |
| PowerPoint | CPO·경영진 10~15장 요약, 면접 발표자료 |
| OneNote(선택) | 인터뷰 메모와 개인 작업노트. 최종 근거는 Git 문서로 이관 |

Microsoft 파일은 바이너리 diff가 어렵다. 핵심 원천데이터는 CSV/YAML/Markdown으로 함께 관리하고 Office 파일은 릴리스 산출물로 생성한다. 민감한 원본은 Git에 두지 않는다.

## 7. 최소 하드웨어 가정

- CPU 가상화 지원, 4코어 이상 권장
- RAM 16GB 권장, 8GB면 동시 VM 수를 줄이고 Docker 중심으로 구성
- 여유 디스크 60~100GB 권장
- Host-only/NAT 가상 네트워크 사용

비용을 줄이기 위해 클라우드 VM을 기본안에서 제외한다. 성능이 부족하면 4개 조직을 동시에 띄우지 않고 단계별 스냅샷 또는 Docker 네트워크로 재현한다.

## 8. 유료 선택지와 채택 여부

| 선택지 | 예상 비용 성격 | 채택 | 판단 |
|---|---|---|---|
| ISO/IEC 27701:2025 공식 원문 | 1회 구매, 국가·판매처별 상이 | 기본 미채택 | 합법적 기관 열람권이 있으면 사용; 없으면 공개정보 참고로 범위 제한 |
| GitHub Team | 사용자당 월 구독 | 미채택 | 개인 프로젝트는 Free로 충분 |
| Microsoft 365 신규 구독 | 월/연 구독 | 해당 없음 | 이미 사용 중 |
| ChatGPT 신규 구독/API | 월 구독 또는 사용량 | 해당 없음/선택 | 기존 구독 활용, API 자동화는 필수 아님 |
| 상용 취약점 스캐너 | 월/연 또는 자산 기준 | 미채택 | 프로젝트 범위와 100시간에 과도함 |
| 클라우드 서버 | 시간/월 과금 | 미채택 | 로컬 VMware·Docker 사용 |
| Git LFS 대용량 저장 | 저장·전송량에 따라 과금 가능 | 가급적 미채택 | 대형 증적·VM은 Git 밖에 보관 |

## 9. 예상 신규 비용

### 필수 신규비용

`0원`을 목표로 한다.

### 발생 가능한 선택비용

- ISO 원문을 개인 구매하기로 결정한 경우의 1회 비용
- GitHub Actions/LFS 무료 한도를 넘기는 경우
- 기존 Microsoft 365 또는 ChatGPT 구독 갱신비용
- 저장장치 용량이 부족할 경우 외장 SSD 비용

선택비용이 발생하기 전에는 무료 대안, 범위 축소와 재현성 영향을 비교한 뒤 의사결정 기록을 남긴다.

## 10. 도구 선택 기준

새 도구를 넣기 전에 다음을 확인한다.

1. 프로젝트 핵심 질문에 직접 기여하는가?
2. 기존 도구로 같은 결과를 낼 수 없는가?
3. 무료 라이선스와 재배포 조건이 명확한가?
4. 개인정보 또는 코드를 외부 서비스에 전송하는가?
5. 결과를 Git과 테스트로 재현할 수 있는가?
6. 설치·학습시간이 100시간 범위에 적절한가?

도구의 수보다 판단과 증적의 품질을 우선한다.
