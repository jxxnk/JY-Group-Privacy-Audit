## 1. 범위와 결과

범위는 로컬 Zammad 한 대와 그 안의 논리 역할이다. Retail이 목적을 정하고 Service가 상담하며 Vendor가 유지보수한다. 결제, 배송, 마케팅, 백업 복구 실측은 범위 밖이다.

초기 Checks 24행은 적합 8, 미흡 13, 미확인 2, 적용 제외 1이다. 현재 FinalReview도 24행이고 초기 미흡을 재점검 적합으로 바꾸지 않았다. 현재 위험은 F-01, F-02a, F-02b가 각 6점, 계획이고 F-03은 9점, 우선이다. F-01과 F-02의 잔여 점수는 미확인이라 만들지 않았다. F-03 잔여는 9점, 우선이다.

F-01 대상은 T02 #52020이고 내부ID는 미확인이다. #52003과 id 3은 S04 정상업무의 별도 티켓이다.

다운로드 사본은 관측했다. 백업 보존과 복구는 미확인이다. 현재 `docs/data-flow.pdf`는 68918바이트이고 SHA256은 `d94e86cd325051ff98b8f4dcd9de31e4440fba6d1c48321e416e498998c51347`이다. 2026-10-14에 기록한 68024바이트 `d94f7cb9cf1191f79a34df5c13061239aa5fdb0f884ada71483c7743c69f023f`는 이력이다.

업로드본이 적은 closeout 브랜치는 `docs/closeout-deliverables-02`다. 그 업로드본의 main `35b7b85`와 태그 `v1.0-final`은 이 인계서에서 다시 확인하지 않았다. 태그 `v1.0-final.1`과 GitHub Release는 만들지 않았다. GitHub Issue #1은 열지 않았고, 같은 기록은 이 파일에 남긴다.

## 3. 기동과 중지

런타임 위치는 `C:\JY-Lab\zammad-runtime`이다.

상태: `docker compose ps`

기존 컨테이너 기동: `docker compose start`

중지: `docker compose stop`

`docker compose down -v`는 하지 않는다. 이 인계서를 쓰는 동안 런타임을 기동하거나 중지하지 않았다.
