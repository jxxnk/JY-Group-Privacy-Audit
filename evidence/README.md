# Evidence Handling

## 디렉터리

- `before/`: 개선 전 원본 참조 위치. 내용은 기본적으로 Git 제외
- `after/`: 재점검 원본 참조 위치. 내용은 기본적으로 Git 제외
- `sanitized/`: 공개 가능한 합성·마스킹 샘플만 저장

Git에 올릴 증적에는 실제 개인정보, 계정 비밀, 내부 IP·호스트명, 접근 토큰과 원본 패킷을 포함하지 않는다. 원본이 저장소 밖에 있으면 파일 해시, 수집시각, 자산 ID, 보관위치 식별자와 수집기 버전만 인덱스에 기록한다.

증적은 발견사항의 결론을 뒷받침하지만 단독으로 업무상 필요성이나 법적 적합성을 확정하지 않는다.
