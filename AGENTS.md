## Non-negotiable rules

- This is a fictional JY Group privacy consulting portfolio.
- Never use real personal data, credentials or unauthorized targets.
- PIPA and ISMS-P are the primary baselines.
- ISO/IEC 27701 is reference material only within lawful access.
- The critical infrastructure guide is used only for technical checks.
- Automation collects evidence; a human makes final compliance decisions.
- Preserve existing user work and keep changes inside the requested scope.
- Update `PROJECT_STATE.md` after a milestone or merged PR.
- Follow `docs/GIT_WORKFLOW.md` for branch, commit and PR behavior.
- Do not claim official certification, legal advice or complete compliance.

## Completion report

Report changed files, validation commands and results, limitations, and the next recommended Issue. Do not say a task is complete when tests were not run.
