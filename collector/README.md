# Evidence Collector

기술 증적수집기의 소스, 점검정의와 테스트를 관리한다. 이 도구는 개인정보 보호법 또는 인증 적합성을 자동판정하지 않는다.

## 예정 구조

- `src/`: 수집, 정규화, 마스킹과 출력 코드
- `checks/`: 점검 ID, 지원 플랫폼, 기대 증적과 매핑 정의
- `tests/`: 정상·오류·마스킹·통합 테스트

## 처리 흐름

1. 승인된 가상 자산과 점검 범위를 읽는다.
2. 읽기 전용 명령으로 원시 증적을 수집한다.
3. 공통 스키마로 정규화한다.
4. 비밀·개인정보·내부 식별정보를 제거한다.
5. `확인 필요`, `개선 후보`, `자동수집 불가` 중 하나를 제안한다.
6. 사람이 업무목적·예외·증적 충분성을 확인해 최종판단한다.

첫 구현은 Linux 로컬 수집과 JSON 출력으로 범위를 제한한다. 원격수집, Windows, DB 종류 추가는 별도 Issue에서 결정한다.
