# Control Mappings

개인정보 보호법, ISMS-P, ISO 공개 참고주제, 주통기 기술 확인방법과 JY 내부통제를 연결한다.

- 기준의 성격과 버전을 구분한다.
- 법률 조문 제목만으로 적합성을 판정하지 않는다.
- 자동화 가능 여부와 사람이 판단할 맥락을 별도 필드로 둔다.
- 원천 매핑은 CSV/YAML로 유지하고 Excel은 산출물로 생성한다.

초기 통합 통제 도메인은 `GOV`, `INV`, `LAW`, `TPR`, `IAM`, `NET`, `SYS`, `LOG`, `LIFE`, `IR`, `ASSURE`다.
